<p><strong>McQueen VPN</strong> is a minimalist, user-friendly Android VPN designed around a simple one-tap workflow: choose a country, tap Connect, and browse securely.</p>

<h3>Key Features</h3>
<ul>
  <li><strong>One-Tap Country Selection:</strong> Pick a location without editing server links, UUIDs, subscriptions, or protocol parameters.</li>
  <li><strong>Dual-Engine Routing:</strong> Supports Xray-core protocols (VLESS, VMess, Trojan, Shadowsocks, Hysteria2, WireGuard) and Aether WARP / MASQUE tunnels.</li>
  <li><strong>Automatic Aether Identity Provisioning:</strong> First-run WARP identities are registered automatically and persisted securely in app-private storage.</li>
  <li><strong>Automatic Same-Country Failover:</strong> Probes candidate routes and seamlessly fails over within the selected country if a server is unreachable.</li>
  <li><strong>Live Telemetry &amp; Controls:</strong> Real-time upload/download throughput, session timer, Quick Settings tile, Home Screen widget, and Dark/Light/System themes.</li>
  <li><strong>Remote Server Directory Sync:</strong> Refreshes HTTPS server manifests on startup and periodically in the background, with optional Bearer token support for private endpoints.</li>
</ul>
